Troubleshooting

Common access problems and practical checks

If something is not working, check the following common causes before trying the service again.

Login Not Working

Check username, password, Caps Lock and try the password reset option if available.

OTP Not Received

Check network coverage, wait briefly and try the resend OTP option.

Registration Failed

Recheck required information and clear browser cache or cookies if necessary.

App Not Opening

Check for updates, clear app cache or reinstall when appropriate.

Attendance Issue

Check your internet connection and allow time for system synchronization.
